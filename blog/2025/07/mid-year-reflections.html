2025년 상반기 회고와 하반기 실행 전략

상반기에는 새로운 정적 블로그 플랫폼 구축과 팀 내 개발 문화 개선이라는 두 가지 목표를 중심으로 달려왔습니다. 덕분에 코드 품질과 협업 효율이 크게 높아졌지만, 돌이켜 보면 아쉬운 부분도 적지 않았습니다. 이번 글에서는 상반기에서 얻은 통찰과 7월 16일을 기점으로 세운 하반기 실행 전략을 기록해 두려 합니다.

상반기 핵심 성과

  • 콘텐츠 파이프라인 자동화: 마크다운 기반 작성 → PR → 배포까지 30분 이내로 단축했습니다.
  • 디자인 시스템 정비: PostCard, Navigation 등 공용 컴포넌트를 문서화하여 재사용성을 확보했습니다.
  • 학습 커뮤니티 운영: 매주 수요일 스터디를 통해 Next.js 15 베타 기능을 실험하고 피드백을 공유했습니다.

놓친 것들에서 배운 점

  1. 테스트 커버리지 부족
    UI 스냅샷 테스트에 집중하다 보니 상호작용 테스트가 부족했습니다. 사용자 여정 전반을 검증하기 위해 Playwright 기반 E2E 테스트를 도입할 예정입니다.
  2. 문서화 지연
    새로 만든 컴포넌트의 props 설명이 Wiki에 늦게 반영되면서 온보딩 속도가 떨어졌습니다. 코드 머지와 동시에 요약 문서를 남기는 것을 규칙화하려 합니다.
  3. 작업 집중 시간 관리 미흡
    오전에는 회의가 몰리고 오후에는 집중력이 떨어지는 패턴이 반복되었습니다. 타임블록 캘린더를 재편하여 화·목 오전을 ‘Deep Work’ 시간으로 예약했습니다.

하반기 실행 전략

1. 콘텐츠 깊이 강화

  • 월 2회 이상 기술 아티클 발행
  • 독자 질문 기반 보완 글 작성
  • 실험적인 UI/UX 시리즈 진행

2. 품질 지표 도입

  • Lighthouse 성능 90점 이상 유지
  • CI 파이프라인에서 pnpm test && pnpm lint를 필수 단계로 강제
  • 주요 페이지에 RUM(Real User Monitoring) 스크립트 추가

3. 학습 루틴 고도화

주차 주제 목표
1주차 React Server Components 기존 CSR 페이지 전환 전략 수립
2주차 Edge Functions 지연 시간 30% 절감
3주차 Observability 로그/트레이싱 통합
4주차 AI 도구 활용 작성-검수 자동화 실험

실천 체크리스트

  • 콘텐츠 주제 목록 10개 이상 확보
  • E2E 테스트 최소 5개 작성
  • 위클리 리포트 템플릿 완성
  • Deep Work 시간 4주 연속 지키기

마무리

올해 상반기는 토대를 닦는 시간이었다면, 하반기는 속도를 붙일 차례입니다. 7월 16일 현재의 다짐을 기록해 두면 연말에 더 명확한 성과를 측정할 수 있을 것입니다. 같은 목표를 가진 분들이 있다면 경험을 나눠 주시면 좋겠습니다. 우리 모두 원하는 방향으로 한 걸음씩 나아가기를!
