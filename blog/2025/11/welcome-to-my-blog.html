정적 블로그 사이트 구축 완료!

안녕하세요! 오늘 드디어 Next.js와 마크다운을 사용한 정적 블로그 사이트 구축을 완료했습니다. 🎉

프로젝트 시작

이 블로그는 GitHub Pages에 호스팅할 수 있는 정적 사이트 생성기(SSG)로 만들어졌습니다. 마크다운 파일로 글을 작성하면 자동으로 아름다운 웹 페이지로 변환됩니다.

주요 기능

1. 마크다운 지원

마크다운으로 글을 작성할 수 있어 매우 편리합니다:

  • 굵은 글씨와 기울임 지원
  • 코드 블록 하이라이팅
  • 리스트, 링크, 이미지 등 모든 마크다운 기능

2. 태그 및 카테고리

각 포스트에 태그와 카테고리를 지정하여 분류할 수 있습니다:

  • 태그: #Next.js, #블로그, #정적사이트
  • 카테고리: 개발, 프로젝트 등

3. 월별 파일 관리

파일을 월별로 관리하여 체계적으로 정리할 수 있습니다:

content/blog/
  └── 2025/
      └── 11/
          └── welcome-to-my-blog.md

4. 다크모드 지원

사용자가 원하는 테마를 선택할 수 있습니다:

  • 라이트 모드
  • 다크 모드
  • 시스템 설정 자동 감지

기술 스택

이 프로젝트에서 사용한 주요 기술들:

기술 용도
Next.js React 프레임워크
TypeScript 타입 안정성
Tailwind CSS 스타일링
Remark/Rehype 마크다운 처리
Highlight.js 코드 하이라이팅

코드 예제

다음은 간단한 React 컴포넌트 예제입니다:

import Link from 'next/link';

export default function PostCard({ post }) {
  return (
    <article className="post-card">
      <Link href={`/blog/${post.slug}`}>
        <h2>{post.title}</h2>
      </Link>
      <p>{post.excerpt}</p>
    </article>
  );
}

앞으로의 계획

앞으로 이 블로그에 다음과 같은 내용을 작성할 예정입니다:

  2. 기술 학습 내용
  3. 프로젝트 후기
  4. 일상적인 생각들
